# Phishing URL Detector

A machine learning web application that detects whether a website 
is phishing or legitimate using Random Forest classification.

## Accuracy
97% on test data

## Tech Stack
Python | Flask | Scikit-learn | Random Forest | HTML | CSS

## Features
- 31 URL-based features analyzed
- Real-time prediction
- Clean dark themed web interface
- Trained on 11,000+ URLs

## How to Run
pip install flask scikit-learn pandas
cd app
python app.py

## Project Structure
- model/ - ML training code and saved model
- app/ - Flask web application
- dataset/ - Training data
